Firm OS Companion

Pair this browser

The companion shows your current Firm OS task beside the page you are working on. Pair it once with a token from the Companion page in Firm OS.

Pairing token

Create one on the Companion page in Firm OS. It is shown there only once and kept here, in this browser only.

Firm OS address

The only address this extension contacts. It is set when the extension is built; ask your admin for a copy built for another address.

Privacy

  • Stored in this browser: your pairing token, and which steps you ticked for the current job (cleared when the browser closes).
  • Fetched: your current task from Firm OS, about once a minute while the side panel is open.
  • Never: it does not read, fill or submit any web page, has no access to the sites you visit, and never files, signs, pays, enters an OTP or sends anything.
